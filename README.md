# 📚 StudySync

A modern and responsive educational platform frontend built using **HTML, CSS, and JavaScript**.
Designed with a clean UI, dark mode support, and fully adaptable layout for all screen sizes.

---

## 🚀 Features

* 🌐 Fully responsive design (mobile, tablet, desktop)
* 🌙 Dark mode toggle
* 🎨 Clean and modern UI
* 📅 Dynamic footer year (auto-updates)
* ⚡ Fast and lightweight (no frameworks)

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## ▶️ How to Run

1. Clone the repository:

```
git clone https://github.com/your-username/studysync.git
```

2. Open the project folder:

```
cd studysync
```

3. Run the project:

* Open `index.html` in your browser
  **OR**
* Use Live Server in VS Code
